# 运动骨盆初步试验结果

完整说明见上级 `PELVIS_README.md`。本目录使用经过坐标/定义核对的Yang图4可见蓝线数字化及遮挡段近似重建，**不是真实个体测量轨迹**。骨盆俯仰是人为设定的扰动，不来自Yang论文。

pilot为4个工况，每个G0/G1/G2/Oracle：固定骨盆、2°同频零相位、5°半频90°、5°双频180°。每组24秒，传感器100 Hz。

- `suite_metrics.json`：全部指标。
- `pelvis_comparison.png`：骨盆扰动下的感知、跟踪误差及基座功。
- 各工况下 `comparison.png`、`control_comparison.png`：控制模式对比。
- 各组 `sensors_100hz.csv`、`physics.csv`：传感器、力矩、人机连接与基座功率记录。
- `validation/report.json`：零扰动退化、五IMU解析比力/陀螺对照、G2因果回放、步长减半与重建敏感性。
- `suite_validation.json`：完成后核对各组相同输入、100 Hz同步、零膝助力与求解器警告。

人体机械功指标必须与基座外部驱动功共同解释，不能直接作为代谢或水下推进效率。膝曲线有遮挡；两种重建在角度上最大相差约3.98°。同一12秒高频扰动G2验证中，重建方法改变人体正功约2.4%，说明不确定性对代理指标有实际影响。
