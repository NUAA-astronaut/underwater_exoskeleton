# 交替打腿外骨骼无助力运动感知仿真：第一阶段

本项目为可运行的研究原型，人体身高参数 1.75 m、质量 70 kg。固定骨盆及外骨骼腰部支撑、水平俯卧、仅矢状面屈伸、踝关节固定。重力保留，不计算水动力、浮力、接触碰撞或推进速度。地面仅用于显示。

## 运行

在 PowerShell 中：

```powershell
Set-Location E:\reasearching\flutter_kick_sim
.\.venv\Scripts\python.exe simulate.py
.\.venv\Scripts\python.exe simulate.py --viewer
.\.venv\Scripts\python.exe validate.py
```

第一条生成 24 秒数据和图表；第二条打开交互模型窗口并实时运行；第三条执行独立几何、传感器轴向、采样同步、零力矩和物理步长减半验证。提前关闭窗口时至少运行 7 秒才能生成稳态统计。若需新建环境：`python -m venv .venv`，随后使用该环境的 pip 安装 `requirements.txt`。

其他示例：

```powershell
.\.venv\Scripts\python.exe simulate.py --duration 60 --out output_60s
.\.venv\Scripts\python.exe simulate.py --ideal --out output_no_noise
.\.venv\Scripts\python.exe simulate.py --dt 0.0005 --out output_half_dt
```

`--ideal` 仅关闭人为传感器噪声及零偏，动态加速度引入的倾角误差仍然存在。修改 `config.json` 可调整人体、绑缚、控制和传感器参数。生成的 model.xml 用于模型检查；实际 PD 控制与柔性绑缚力在 Python 中实现，单独打开 XML 不会复现完整试验。

## 模型与坐标

- 世界 X 轴由髋指向初始伸直的腿部，Z 轴竖直向上，Y 轴沿髋膝屈伸轴。左右腿在 Y 方向分开。
- 人体髋角为绕 +Y 的转角，膝屈曲为绕 -Y 的转角；两侧使用相同解剖角度正方向。
- 人体与外骨骼分别具有四个关节，共 8 个自由度。初始轴线重合；轴线上侧方电机与人体关节中心的 Y 坐标不同，不影响初始同轴。
- 外骨骼髋轴固定在腰部支撑上；膝轴随外骨骼大腿杆运动，因此可以与人体膝中心出现小幅偏移。平面模型不模拟轴线倾斜。
- 绑缚位于大腿、小腿各自长度的 70%。外骨骼侧用虚拟袖套连接点跨越侧向距离，使两条运动链在初始姿态的连接点重合。
- 每对连接点施加等大反向的 `F = k*(p_exo-p_human) + c*(v_exo-v_human)`；通过点雅可比转为广义力，包含力臂作用。该模型表示局部线性柔性连接，不表示真实绑带的张力单向性、松弛、皮肤滑移或接触压力。
- 金属杆件为刚体；关节采用可转动铰链。DM-J6006-2EC 以质量、被动阻尼/摩擦、等效转子惯量及零力矩执行器近似，不是厂家完整机电模型。
- 四个人体执行器采用带重力/科氏偏置补偿的 PD 力矩控制和 150 Nm 限幅；这不是肌肉或 EMG 模型。四个外骨骼执行器始终为零主动输出，不施加位置伺服或重力补偿。

## 人体尺寸、质量和脚蹼

大腿长度为 `0.245*height`（0.42875 m），小腿为 `0.246*height`（0.43050 m）。每侧大腿、小腿、足部分别使用人体质量的 10%、4.65%、1.45%；其余 67.8% 集中于固定骨盆/躯干。人体总质量恰为 70 kg；每只脚蹼另加 0.5 kg，不计入人体质量。固定骨盆上的质量不参与自由运动。

这些比例是本原型的工程近似，未按该用户实测肢段辨识。几何惯量由简化胶囊体/长方体计算。175 cm 是人体参数化尺度，不是包含脚蹼后的外形总长。足与小腿初始沿同一方向固定，属于流线型姿态假设，未映射为临床定义的具体踝角。

外骨骼杆件质量（0.35/0.25 kg）、电机质量（0.335 kg）、阻尼、摩擦、armature、绑缚刚度（2500 N/m）和阻尼（45 Ns/m）均为待实测核对的参数。没有把电机额定扭矩用于限制人体驱动力矩。

## 轨迹和论文使用边界

参考 Yang 等，2026，DOI: https://doi.org/10.1016/j.jbiomech.2026.113285 的正常速度条件，设置 0.67 Hz 周期，以髋/膝关键角度与时刻构造周期三次样条。左右相差半周期是本项目假设。

这不是论文原始数据或图像数字化复现。中间控制点为人工近似，样条可能出现峰值过冲；PD 跟踪也存在误差。因此输出 ROM 和峰值不必等于论文表 2，不能据此声称准确复现论文。后续获得数字化或原始周期数据后，应替换 HIP/KNEE 曲线，并校核角度零点、ROM、角速度峰值及相位。固定踝关节后不研究髋—膝—踝完整协调，也不重现肌肉协同。

0–2 s 为静止准备，1–1.8 s 用于陀螺零偏估计，2–4 s 平滑增加运动幅度；6 s 后计算稳态指标。

## 五 IMU 与编码器

五个 IMU 位于人体骨盆、左/右大腿、左/右小腿。大腿和小腿 IMU 放在肢段前侧附近，位置相对于旋转中心的偏置参与加速度计算。假设传感器与人体刚体牢固连接，不包含皮肤软组织伪影。

默认 1000 Hz 物理积分、100 Hz 输出。每次采样在同一时刻重新计算状态、控制、绑缚力和传感器，避免位置与加速度相差一个物理步。时间戳取整数步数生成。CSV 是浮点 SI 单位，非 CAN 报文。

原始加速度是 IMU 局部坐标系的比力，陀螺是局部角速度。对于固定在 world 上的骨盆，当前 MuJoCo 构型返回零静态加速度，因此显式使用 `-R_site^T * gravity` 构造受支撑的静态比力，其余四个 IMU 使用引擎 accelerometer。静止时各传感器比力模长应约为 9.81 m/s²。

安装角使用已知的绕 Y 固定旋转（0、7、-5、-6、4 度）进行 sensor-to-segment 变换；不是从单次静止姿态估计未知三维安装矩阵。静止阶段估计初始倾角及陀螺零偏。运动阶段使用平面互补滤波：陀螺梯形积分预测，加速度倾角作低增益修正，并按加速度模长偏离重力的程度降权。动态加速度即便模长接近重力也会造成误差，当前滤波器不消除此问题。

人体肢段绕 Y 的姿态角 theta 等价于旋转矩阵 Ry(theta)。髋角为 `theta_thigh - theta_pelvis`，膝角为 `theta_thigh - theta_shank`；这是严格平面条件下相对旋转的标量形式，不是通用三维欧拉角相减法。角速度由变换到统一轴后的相邻陀螺差分取得。无磁力计，不估计三维航向。

HWT905-CAN 在本阶段仅为后续硬件目标。噪声和固定零偏为可复现的假设值，尚未依据实测标定；未实现 CAN 编解码、量化、时延、丢包、内部带宽和硬件饱和。不能把本结果解释为 HWT905 的实测精度或厂家内部算法。

编码器当前为外骨骼关节的理想位置/速度读数，没有额外量化和噪声。姿态滤波器不使用编码器或人体关节真值反馈；真值只用于控制、记录和评价。人体运动与编码器运动的差异不归为 IMU 误差。

## 结果文件

- `output/model.xml`：生成的 MuJoCo 几何、惯量、关节与传感器模型。
- `output/config_used.json`：该次配置；随机种子固定为 42。
- `output/sensors_100hz.csv`：100 Hz 原始 IMU、姿态估计/真值、关节目标/真值/估计、编码器及驱动力矩。
- `output/metrics.json`：稳态角度/角速度误差、跟踪误差、人机差异、频率、ROM、最大绑带力/位移、力矩及求解器警告。
- `output/model_preview.png`：仿真模型截图。
- `output/joint_analysis.png`：关节角及两类误差。
- `output/joint_velocity.png`：关节角速度对比。
- `output/imu_signals.png`：五个 IMU 的三轴加速度与陀螺曲线。
- `validation/report.json`：独立检查与 1 ms/0.5 ms 步长对比。

频率使用稳态段周期图估计，分辨率取决于分析时长；骨盆静止，主运动频率记为 null。角度误差用 wrap 后的差值计算。姿态误差是平面倾角误差，不是完整三维姿态误差。

MuJoCo 参考：https://mujoco.readthedocs.io/en/stable/XMLreference.html 及 https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html 。
