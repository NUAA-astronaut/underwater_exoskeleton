# 默认四组助力实验结果

完整建模、接口、字段和运行说明见上级目录 `ASSISTANCE_README.md`。

本目录独立于原无助力 `output/`。每组24秒，默认物理频率1000 Hz、传感器100 Hz；代理指标统计6–24秒。电机限制参数为工程占位值，不是 DM-J6006-2EC 实测规格。

| 组别 | 人体四关节力矩向量RMS / Nm | 人体正机械功 / J | 合并跟踪RMSE / ° | 外骨骼净机械功 / J |
| --- | ---: | ---: | ---: | ---: |
| G0 | 74.778 | 1625.270 | 2.577 | 0.000 |
| G1 | 74.425 | 1600.077 | 2.495 | 72.112 |
| G2 | 74.484 | 1600.220 | 2.515 | 78.124 |
| Oracle | 74.501 | 1600.373 | 2.518 | 77.918 |

以上为本次默认参数结果，重跑或修改配置后应以各组 manifest 和 JSON 为准。G2没有显示优于G1，Oracle也不是最优辅助收益上界。三种辅助模式的正机械功代理约下降1.5%，不能解释为人体代谢或水下推进收益。

`comparison_metrics.json` 保存完整组间比较及相对G0变化；`comparison.png` 为代理指标图；`control_comparison.png` 展示力矩、跟踪与相位误差。每组CSV含传感器、编码器、实际力矩、人体控制分量、相位、绑带力/位移。`physics.csv` 用于物理频率功率积分，`sensors_100hz.csv` 为100 Hz输出。

独立验证结果见 `validation/report.json`；验证完成且 passed=true 才能视为通过数值与接口检查。实物传感器、实际电机与绑带参数尚未验证。
